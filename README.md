## 📖 Overview

**CustomItem-Full** is a powerful add-on for PocketMine-MP that adds **100+ exclusive custom items** to your server. It includes **FBI & Military suits**, **custom swords**, **wings**, **hats**, and complete **armor sets**!

> ⚠️ **This plugin requires [Customies](https://github.com/CustomiesDevs/Customies) to work!**
